# WordPress 3-Tier Architecture on AWS

## Project Overview
Implemented a scalable and reliable WordPress deployment on AWS using EC2, RDS, AMI, Load Balancer, and CloudFront services.

## AWS Services Used
- EC2
- RDS
- AMI
- Load Balancer
- CloudFront

## Features
- Scalable Web Hosting
- Centralized Database Management
- Load Balancing for High Availability
- Faster Content Delivery using CloudFront
- Backup and Replication using AMI

## Deployment Workflow
User → CloudFront → Load Balancer → EC2 → RDS
